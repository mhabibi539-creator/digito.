# DIGITO PREMIUM — نسخه دسکتاپ ویندوز

این پروژه، فایل اصلی `DIGITO-Premium-v3-4.html` را در یک پنجره دسکتاپ Electron اجرا می‌کند. منطق و رابط کاربری برنامه عمداً دست‌نخورده نگه داشته شده تا منوها و ابزارهای موجود حذف یا بازنویسی نشوند.

## ساخت فایل نصب ویندوز

1. پوشه را روی یک سیستم Windows 10/11 شصت‌وچهاربیتی استخراج کنید.
2. Node.js نسخه LTS را از وب‌سایت رسمی `https://nodejs.org` نصب کنید.
3. اتصال اینترنت را برای دریافت Electron و ابزار ساخت نصب‌کننده برقرار کنید.
4. روی `build-windows.bat` دوبار کلیک کنید.
5. پس از پایان، فایل نصب در پوشه `dist` با نامی شبیه `DIGITO-PREMIUM-Setup-3.4.0-x64.exe` قرار می‌گیرد.

یا در ترمینال همین پوشه اجرا کنید:

```powershell
npm install
npm run dist:win
```

## امکانات پوسته دسکتاپ

- پنجره مستقل ویندوز با حداقل اندازه مناسب
- نصب‌کننده NSIS با انتخاب مسیر نصب
- ساخت میان‌بر دسکتاپ و منوی Start
- پنجره استاندارد Save As برای فایل‌های خروجی
- چاپ با Ctrl+P و منوی فایل
- نگهداری LocalStorage در پروفایل برنامه Electron در ویندوز
- باز شدن لینک‌های وب در مرورگر پیش‌فرض سیستم
- غیرفعال بودن دسترسی Node.js از داخل صفحه برای جداسازی امنیتی

## نکته مهم درباره آفلاین بودن

پوسته دسکتاپ و ابزارهایی که وابستگی خارجی ندارند، پس از نصب بدون اینترنت اجرا می‌شوند. در نسخه HTML فعلی، موتور OCR یعنی Tesseract.js و کتابخانه‌های PDF.js و pdf-lib از CDN اینترنتی بارگذاری می‌شوند؛ بنابراین OCR و برخی عملیات PDF در حالت کاملاً آفلاین تضمین‌شده نیستند. برای آفلاین‌سازی کامل باید فایل‌های موتور OCR، داده‌های زبان فارسی/انگلیسی و کتابخانه‌های PDF به‌صورت محلی به پروژه افزوده و مسیرهای بارگذاری در HTML اصلاح شوند.

## داده‌ها و پشتیبان

اطلاعات LocalStorage این نسخه در پروفایل محلی Electron ذخیره می‌شود و با پاک‌کردن داده‌های برنامه یا حذف دستی پروفایل ممکن است از بین برود. از ابزار «پشتیبان‌گیری» داخل خود DIGITO به‌صورت دوره‌ای خروجی JSON بگیرید.

## وضعیت خروجی

این پوشه، سورس آماده ساخت نصب‌کننده ویندوز است؛ فایل EXE نهایی باید روی Windows (یا CI ویندوزی) ساخته شود. ساخت EXE در محیط فعلی انجام نشد، چون این محیط لینوکسی است و دسترسی شبکه برای دریافت Electron/NuGet/npm در دسترس نبود.
